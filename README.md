# readipv4

Read validation gates for ipv4 inputs before they hit prod.

**Site:** https://theworker02.github.io/readipv4/

## Install / run

```bash
git clone https://github.com/theworker02/readipv4.git
cd readipv4
node src/cli.js
node --test
```
